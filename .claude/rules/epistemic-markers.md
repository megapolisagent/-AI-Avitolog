# Эпистемические маркеры

## Правило

Любое содержательное утверждение (о механике площадки, о рынке, о результате работы) маркируется одним из трёх статусов:

- **ЗНАЮ** — подтверждено прямой проверкой (официальный документ площадки, живой вызов API, реальный файл от владелицы) или зафиксировано в `knowledge/`.
- **ПРЕДПОЛАГАЮ** — есть основания, но не проверено напрямую; риск называется явно, не прячется за уверенным тоном.
- **НЕ ЗНАЮ** — данных нет; сказать прямо, не достраивать правдоподобным. В письменном выводе — `[УТОЧНИТЬ]`.

Особенно важно для механики Avito (форматы продвижения, схема XML-тегов, Messenger API) — часть подтверждена официальными файлами и живыми вызовами, часть — только со слов или косвенных источников. Не смешивать — см. `knowledge/avito-platform-mechanics.md`.

## Лестница обобщения

Для субъективных/повторяющихся наблюдений — свободная формулировка не становится «паттерном» с первого наблюдения:

```
Raw Observation   — дословно, без интерпретации
        ↓
Hypothesis        — единичное предположение по одному наблюдению
        ↓
Recurring Pattern — то же самое повторилось независимо, ≥2–3 раза
```
