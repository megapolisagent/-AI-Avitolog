# Доступ к внешним данным о рынке

## Каналы

- **Официальный API Avito своего аккаунта** — основной канал (Автозагрузка, Авторизация, Продвижение, Мессенджер, аналитика). Ключи — `.env`.
- **Apify** — подключён по прямому решению владелицы (2026-09-09) для сбора открытых рыночных данных, когда официального API недостаточно. Соответствие условиям целевых площадок при таком сборе — её деловое решение и её ответственность, не техническое ограничение агента.
- **Официальные сайты застройщиков** о их собственных объектах — открытая публичная информация, читать напрямую.
- **Материалы, переданные вручную** — файл в `data/market_raw/`, данные лота в `data/lots/` — всегда валидный вход.

## Перед обращением к новому домену, которого нет в уже проверенных

1. Это официальный сайт застройщика о его собственных объектах — не что-то, требующее обхода защиты?
2. Если сомневаешься в правовом статусе конкретного канала — не открывать молча, спросить владелицу/Engineer.
