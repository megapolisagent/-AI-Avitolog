# Источники данных о рынке

## Каналы

- **Официальный API Avito своего аккаунта** — основной канал (Автозагрузка, Авторизация, Продвижение, Мессенджер, аналитика). Ключи — `.env`.
- **Apify** — платформенный инструмент для сбора открытых рыночных данных: цены, планировки, акции конкурентов по целевому ЖК/локации.
- **Официальные сайты застройщиков** о их собственных объектах — открытая публичная информация, читать напрямую.
- **Материалы, переданные вручную** — файл в `data/market_raw/`, данные лота в `data/lots/`.

Стандартный рабочий набор для упаковки карточек и оценки конкурентов — использовать уверенно, без лишних согласований на каждый запрос.
