# Avito Listing Packaging

## Принцип

Данные о рынке и о лоте — только те, что реально даны (файл в `data/lots/` — свой лот, `data/market_raw/` — материалы конкурентов). Ничего не досочиняется про то, что происходит на Avito прямо сейчас — нет файла, нет данных, это так и говорится (`HOME.md`, «Ты не делаешь»).

## Первая волна — единый пакет по подтверждённому лоту (главный путь, `DECISIONS.md`, 2026-09-01)

Вход — один файл по шаблону `data/lots/TEMPLATE.md`: данные лота (ЖК, планировка, площадь, этаж, цена, ипотека/рассрочка, ПВ) + портрет покупателя (сегмент: семья/инвестор/наличные — боль, что реально убеждает именно этого человека). Без портрета покупателя текст выходит шаблонным («квартира в продаже») — портрет обязателен, не опция; если не дан — спросить, не писать нейтрально «на всех».

Выход — один пакет, все шесть частей обязательны за один прогон:
1. **Карточка объявления** — заголовок + первый экран + призыв (Модуль 1 ниже, включая правила живого текста).
2. **ТЗ на карусель** — Модуль 1, «ТЗ на фото-карусель».
3. **Лид-магнит** — Модуль 4, под сегмент покупателя из входного файла, не нейтральный шаблон.
4. **Первый автоответ** — Модуль 4, скрипт чат-воронки.
5. **Чек-лист модерации** — «Финальный валидатор» ниже, отмечено пройдено/не пройдено по каждому пункту.
6. **Строка KPI** — одна строка в формате `workspace/kpi-tracker.md` (создать файл, если его ещё нет), добавляется туда же, не только выводится в ответ.

Критерий готовности пакета — не «все разделы заполнены», а «владелец может опубликовать это сегодня без правок»: конкретные числа, не плейсхолдеры там, где данные в файле лота есть; честный `[УТОЧНИТЬ]` только там, где данных в файле реально нет.

## Модуль 1 — Генератор карточки-локомотива

Вход: условия объекта (ЖК, планировка, площадь, цена, ипотечные/рассрочные программы) + сегмент/портрет покупателя (кто это, что для него главное — семья ищет метраж и школу рядом, инвестор — доходность и ликвидность, покупатель с наличными — скорость сделки и скидку).

**Правила живого текста, не шаблона** (усилено 2026-09-01 по разбору реальной практики копирайтинга — `knowledge/evidence/2026-09-01-avitolog-copywriting-humanization-mechanism.md`) — если текст можно вставить в любую другую карточку без изменений, значит он не готов:

- **Банк-лист запрещённых слов** — если слово из списка попало в текст, переписать до того, как отдать результат: «прекрасный», «уникальный», «идеальный», «не упустите шанс», «звоните прямо сейчас», «развитая инфраструктура», «динамично развивающийся район», «выгодные условия», «широкие возможности», «продуманная планировка» — общие слова без факта за ними, любая карточка застройщика их использует.
- **So What? Chain** — на каждый факт из данных лота (площадь/этаж/вид/цена) задать себе «и что?» минимум один раз, пока не дойдёт до реальной выгоды покупателя: «62 м²» → и что? → «хватит на отдельную комнату ребёнку» → и что? → «не нужно переезжать через 3 года, когда семья вырастет». В карточку идёт последний шаг цепочки, не сырой факт.
- Выгода для этого конкретного покупателя, не абстрактная: не «выгодные условия», а что это меняет именно для семьи/инвестора/покупателя с наличными.
- Одна конкретная эмоция или деталь, которая цепляет («вид на парк из окна кухни», не «прекрасный вид»), не список характеристик.
- Призыв — конкретное действие, не «звоните» (см. п.4 ниже).

**Второй проход — критик, обязателен перед выдачей.** После того как текст карточки написан — перечитать его отдельным проходом именно как критик, не автор: (1) есть ли слово из банк-листа выше — если да, переписать; (2) есть ли хоть один факт, прошедший через So What? Chain до реальной выгоды, а не сырая характеристика — если нет, вернуться и доделать; (3) можно ли этот текст вставить в карточку другого ЖК без изменений — если да, недостаточно конкретно, переписать. Не выдавать карточку с первого прохода без этой проверки.

Выход, все четыре части обязательны:
1. **Заголовок** — под поисковые подсказки Avito: тип+комнатность+площадь+ЖК+главный финансовый триггер. Короткий, без воды.
2. **ТЗ на фото-карусель**, не только обложку — обложка (плашка + рендер/планировка с размерами, не типовой фасад), дальше по порядку: 2. зонирование/габариты комнат; 3. вид из окна; 4. архитектура/лобби; 5. инфраструктура двора; 6. схема платежей/график (если есть). Правила по всем кадрам: текст на плашках крупный, читаемый со смартфона (не мелкая подпись); никаких контактных данных (телефон/мессенджер) на самом фото.
3. **Первый экран текста** — только финансовый расчёт: полная цена, ПВ (сумма и %), условия рассрочки/ипотеки, ежемесячный платёж если есть график. Без абзацев про инфраструктуру и локацию — это не первый экран.
4. **Призыв к лид-магниту** — конкретное предложение с действием («Напишите +, пришлю...»), не общее «звоните».

Если каких-то входных данных не хватает (график платежей, точная площадь, портрет покупателя) — плейсхолдер и прямое указание, чего не хватает, не выдуманное число и не нейтральный текст «для всех».

## Модуль 2 — Медиаплан продвижения

Вход: ЖК/локация, число доступных планировок, бюджет (если дан).

Выход:
- Сколько карточек имеет смысл держать одновременно на объект — по осям: разные планировки (1-к/2-к евро/видовые), разные ценовые пороги (входная цена за м² / минимальный платёж по субсидии / полная стоимость — это разные карточки, не один текст), разные акценты (для жизни / для инвестора / семейная ипотека).
- Логика по платным форматам (x2–x10, XL) и времени запуска — с явным маркером ПРЕДПОЛАГАЮ/ЗНАЮ, см. `knowledge/avito-platform-mechanics.md` (пакеты не проверены Engineer напрямую).
- **Анти-дубликат (ЗНАЮ, `knowledge/avito-platform-mechanics.md`).** Несколько карточек на одну планировку разрешены Avito, только если у каждой реально свой текст и своё фото — не один шаблон с разными подставленными цифрами. При выдаче пула карточек — не просто менять цену/акцент в одном и том же тексте, переписывать заголовок и первый экран по-разному под каждый оффер.
- Если бюджет не дан — не выдумывать сумму, спросить или дать логику без привязки к рублям.

## Модуль 3 — Калькулятор финансовых офферов

Вход: полная цена, ПВ, условия рассрочки/ипотеки/субсидии от застройщика.

Выход: таблица «что мы показываем в объявлении» — реальная цена vs заниженный ежемесячный платёж как отдельные, явно подписанные варианты (не подменять один другим молча — это вводит покупателя в заблуждение, и SOUL.md прямо против выдумывания чисел). Показывать оба варианта и рекомендовать, какой использовать для этого сегмента/объекта, с обоснованием.

## Модуль 4 — Скрипт чат-воронки

Вход: главный финансовый триггер карточки (из модуля 1 или 3), сегмент покупателя, если известен (семья/инвестор/наличные) — если не дан, спросить или взять нейтральный вариант.

Выход: первый автоответ (лид-магнит — подборка/расчёт в обмен на простое действие от покупателя), 1-2 уточняющих вопроса для квалификации, финальный шаг — увести на звонок/WhatsApp. Короткие реплики, не абзацы.

**Банк лид-магнитов по сегменту** — не один шаблон на всех, шаблон «пришлю подборку» выгорает при повторном использовании:
- Инвестор: расчёт арендного потока и доходности при выходе через 2 года.
- Семья: сравнение планировок евро-формата с замерами под мебель.
- Покупатель с наличными/быстрая сделка: список закрытых спецпредложений застройщика на этот этаж/корпус (только если такие реально даны владелицей — не выдумывать).

Если сегмент не известен и не спрошен — не выбирать за владелицу (`SOUL.md`, «Не переходит границу в чужую роль»), дать нейтральный вариант и явно спросить.

## Финальный валидатор перед выдачей карточки (Модуль 1)

Перед тем как отдать готовую карточку — проверить по правилам, подтверждённым официально (`knowledge/avito-platform-mechanics.md`), не по догадке:
1. В поле «Цена» — только полная стоимость лота. Первоначальный взнос/платёж по ипотеке или рассрочке — только в тексте описания, никогда не в поле цены.
2. В тексте нет ссылок на соцсети/внешние сайты и нет номера телефона.
3. Этаж указан верно, если он дан во входных данных (сверяется площадкой с Росреестром — ошибка здесь официально названная причина отклонения). Если этажа во входных данных нет — плейсхолдер, не гадать.
4. Не заявлять цену/условие, которых нет во входных данных — «недостоверная цена» официально названная причина блокировки.

Не входит в валидатор (проверено и отклонено как непроверенное): списка запрещённых слов вроде «гарантированный доход» у Avito официально нет — не отказывать в таких формулировках только по этому основанию.

## Разбор конкурентов — только если дан реальный файл

Вход: файл в `data/market_raw/`, вручную положенный человеком (сохранённая страница Avito или скопированный текст карточек). Нет файла — сказать прямо, не переходить к этому модулю.

Разбор по 6 пунктам на каждое объявление в файле:
1. Заголовок — чем цепляет (цена/скидка/локация/УТП).
2. Первые 3 строки описания — какой триггер там главный.
3. Тип цены — реальная стоимость или заниженный платёж по ипотеке/рассрочке.
4. Финансовые триггеры — рассрочка 0%, транши, субсидия, трейд-ин, «только сегодня».
5. Визуальные крючки — что на обложке (если файл содержит описание фото, не только текст).
6. Пробелы — чего у конкурентов нет вообще → это место для УТП владельца.

Итог разбора — не список наблюдений, а прямой вывод: что использовать у себя, чего избегать (то же, что уже делают все), где реальный зазор.
