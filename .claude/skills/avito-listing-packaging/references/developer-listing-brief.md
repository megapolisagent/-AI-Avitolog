# Бриф на упаковку первички (застройщик, ДДУ) — разделение ролей с CMO

> Постоянный стандарт. Полная методология шаблона (Часть 1/2/3, стоп-лист, методологическая база Dunford/Cialdini) — на стороне CMO: `AI Marketing Strategist/.claude/skills/marketing-strategy/references/developer-listing-brief.md`. Этот файл — зеркало таблицы ролей с акцентом на твою часть, держать оба файла синхронно при следующей правке любого из них.

## Когда применяется

Только объекты от застройщиков (первичка, ДДУ) — не для вторички.

## Разделение ролей

| Поле брифа | Кто заполняет |
|---|---|
| Мета (ЖК/класс/лот) + реальная альтернатива на вторичке + текущие условия застройщика | **Ты, субагент `market-analyst`** |
| Часть 1 — выбор рычага и обоснование | CMO |
| Часть 2 — сам текст хука/тела/CTA | **Ты** (исполнение по формуле CMO — `listing-copywriter/SKILL.md`, не придумывается заново) |
| Часть 3 — JTBD-гипотеза | Предлагает CMO, **ты подтверждаешь по реальным обращениям** |
| Стоп-лист | **Ты обновляешь** (субагент `pain-point-extractor`, уже штатная работа), CMO задаёт правило отсечения («встретилось у 5+ конкурентов подряд — в стоп») |

**Финальный рычаг и JTBD-гипотезу ты не придумываешь сам на месте — присылаешь CMO.** Твоя часть — данные о рынке/альтернативе (`market-analyst`), боли из реальных текстов конкурентов (`pain-point-extractor`), исполнение текста по уже выбранной CMO формуле (`listing-copywriter`) и подтверждение JTBD-гипотезы по факту реальных обращений, не изобретение рычага/гипотезы своим чутьём.

## Технические факты, которые нужны для формулы подачи, но пока не подтверждены

Лимит символов текста до «Читать далее», риск пессимизации за спам-теги, предпочтение звонок/чат для первички бизнес-класса — статус и попытки проверки задокументированы в `knowledge/avito-platform-mechanics.md`. Для проверки самой выдачи Авито (не сайта застройщика) — ручная проверка владелицей на боевой карточке в телефоне, `WebFetch` на страницах листинга Авито не проходит (JS-рендер). Для данных с сайта застройщика (`alia.moscow/flats/` и подобные) — `mcp__exa__web_fetch_exa` отдаёт полную страницу с ценами/сроком сдачи, рабочий путь, не автоматический фетч Авито.
