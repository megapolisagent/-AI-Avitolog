# Lead Magnets

## Контекст перед выбором

Бизнес-контекст уже есть в `CLAUDE.md`/`knowledge/` этого репозитория — не спрашивать заново «что делает компания». Спросить только то, чего там нет: сегмент покупателя конкретного лота (из `data/lots/<файл>.md`, «Портрет покупателя») и что реально может закрыть его главное возражение/боль.

## Принципы

1. **Одна конкретная боль, не общая тема.** «Как рассчитать реальный платёж по семейной ипотеке на этот лот» сильнее, чем «гид по ипотеке».
2. **Под сегмент покупателя лота**, не общий для всех: семье — про инфраструктуру/школы/безопасность, инвестору — про доходность/ликвидность, покупателю с наличными — про сравнение с депозитом/альтернативами.
3. **Ценность выше затраченного времени** — читается за 5-10 минут, даёт готовый вывод, не растянутый лонгрид.
4. **Не гарантирует то, чего нет во входных данных лота** — те же правила, что и у самой карточки (`CLAUDE.md`, §8): без реальных цифр — не считать, спросить.
5. **Один формат**, не смешивать (не «чек-лист + видео + таблица» одновременно).

## Банк форматов

| Формат | Когда уместен | Трудоёмкость |
|---|---|---|
| Чек-лист | Быстрый практический шаг («что проверить перед показом», «документы для одобрения ипотеки») | Низкая |
| Памятка/шпаргалка | Справочные цифры (ставки по программам, что входит в стоимость) | Низкая |
| Сравнительная таблица | Инвестору — сравнение с альтернативами (депозит, другой ЖК) | Средняя |
| Расчёт под лот | Персональный платёж/выгода по этому конкретному лоту — считает `listing-fin-offer/tools/calculate_payment.py`, не лид-магнит сам по себе, а его начинка | Низкая (код уже есть) |

## Матрица «сегмент → формат»

| Сегмент | Что убеждает | Формат лид-магнита |
|---|---|---|
| Семья | Инфраструктура, школы/сады, безопасность района | Чек-лист «что проверить в районе перед переездом» |
| Инвестор | Доходность аренды, ликвидность, рост цены | Сравнительная таблица с альтернативами вложений |
| Наличные | Прозрачность цены, что входит в стоимость, экономия vs ипотека | Памятка «из чего складывается полная цена» |

## Выдача

1. **Формат и тема** — какой из банка выше и почему именно для этого сегмента.
2. **Содержание** — 3-5 пунктов, что внутри, откуда цифры (только подтверждённые данные лота).
3. **Как передать** — текст автоответа в чате Avito, предлагающий лид-магнит (это уже часть чат-воронки `listing-copywriter`, не отдельная посадочная страница — её у продукта нет).

## Применимость у Avitolog

`listing-copywriter` (пишет текст самого лид-магнита и предложение в чат-воронке), `listing-fin-offer` (числа внутри лид-магнита с расчётом). Формы захвата, email-нёрчеринг, лендинги, платная реклама, попапы — вне охвата продукта, не часть этого скилла.
