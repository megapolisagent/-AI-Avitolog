# Listing SEO/Geo

## Вход

ЖК, планировка (комнатность), площадь, адрес/локация (район, ближайшее метро/станция МЦК/МЦД если есть), главный финансовый триггер (из `listing-fin-offer`).

## Формула заголовка (ЗНАЮ — уже проверено на практике)

Тип + комнатность + площадь + ЖК + главный финансовый триггер — под поисковые подсказки Avito, короткий, без воды.

Пример: «2-к квартира, 46.2 м², ЖК ALIA — рассрочка 0%».

## Геопривязка — район/метро (методология, ПРЕДПОЛАГАЮ, не проверено официальным фактом Avito)

Покупатель на Avito часто фильтрует недвижимость по району/метро/удалённости раньше, чем по ЖК — если ЖК малоизвестен, заголовок и первые строки описания без геоориентира теряют часть поискового трафика тех, кто ищет «квартира у метро Х», а не по названию комплекса.

Правила:
- **Есть станция метро/МЦК/МЦД в пешей доступности (по данным лота, не гадать)** — указать в тексте (не обязательно в заголовке — там короче), с реальным временем пешком, если оно дано; не «рядом с метро» без конкретики.
- **Название района/административного округа** — упоминать один раз в первых строках описания, не в каждом абзаце (иначе выглядит как переспам ключевых слов, не текст для человека).
- **Смежные/известные ориентиры** (крупный парк, ТЦ, известная улица) — если помогают человеку представить локацию быстрее, чем административное название района. Использовать только реальные, названные во входных данных — не придумывать «рядом с парком», если это не подтверждено.
- Нет данных о метро/районе во входных данных — не выдумывать удалённость и время в пути, оставить `[УТОЧНИТЬ]`.

## Что не делает

Не пишет сам текст первого экрана и призыв (это `listing-copywriter`), не считает платежи (это `listing-fin-offer`), не решает, какие фото ставить в карусель.

## Выход

Заголовок (по формуле выше) + 1-2 строки геопривязки для использования в первых строках описания (передать `listing-copywriter` как готовый ингредиент, не пересчитывать).
