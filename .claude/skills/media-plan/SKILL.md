# Media Plan

> Перенесено из `avito-listing-packaging/SKILL.md`, «Модуль 2 — Медиаплан продвижения» — разбито по Правилу 3 Anthropic, 2026-09-14 (тот же критерий, по которому уже разбиты Модули 1/3/4 на `listing-fin-offer`/`listing-seo-geo`/`listing-copywriter`, 2026-09-10). Содержание не изменилось, только формат.

## Вход

ЖК/локация, число доступных планировок, бюджет (если дан).

## Метод

1. **Сколько карточек держать одновременно на объект** — по осям: разные планировки (1-к/2-к евро/видовые), разные ценовые пороги (входная цена за м² / минимальный платёж по субсидии / полная стоимость — это разные карточки, не один текст), разные акценты (для жизни / для инвестора / семейная ипотека).
2. **Платные форматы (x2–x10, XL) и время запуска** — с явным маркером ПРЕДПОЛАГАЮ/ЗНАЮ, см. `knowledge/avito-platform-mechanics.md` (пакеты не проверены Engineer напрямую).
3. **Ставка CPA/CPX по конкретному лоту (поднять/снизить), и стоит ли вообще включать VAS с учётом текущих цифр кампании** — не считать самому, звать субагента `traffic-manager` (`.claude/agents/traffic-manager.md`) с реальными цифрами лота (текущая ставка, расход, CPA/CPL, целевой порог). Этот скилл отвечает за стратегию пула карточек и формат, `traffic-manager` — за число (ставку/бюджет) под конкретный формат.
4. **Анти-дубликат (ЗНАЮ, `knowledge/avito-platform-mechanics.md`).** Несколько карточек на одну планировку разрешены Avito, только если у каждой реально свой текст и своё фото — не один шаблон с разными подставленными цифрами. При выдаче пула карточек — не просто менять цену/акцент в одном и том же тексте, переписывать заголовок и первый экран по-разному под каждый оффер.
5. Если бюджет не дан — не выдумывать сумму, спросить или дать логику без привязки к рублям.

## Что не делает

Не считает ставку/бюджет под конкретный формат (это `traffic-manager`), не пишет текст карточек (это `listing-copywriter`), не считает финансовый расчёт лота (это `listing-fin-offer`).

## Выход

Стратегия пула карточек: сколько карточек и по каким осям они различаются, какие платные форматы и когда запускать, антидубликат-чеклист перед выдачей пула. Ставка CPA/CPX по конкретному формату — отдельно от `traffic-manager`, не выводится этим скиллом как число.
