# Канцелярит по Норе Галь — диагностика и словарь замен

> Источник: `Halfofthesky/nora-gal` (GitHub, Claude skill по книге Норы Галь «Слово живое и мёртвое»), прочитан целиком лично 2026-09-19, не по описанию. Все списки и примеры — прямые цитаты из книги через этот скилл. Используется как дополнительный, более прицельный диагностический слой конкретно для канцелярита, рядом с общим каталогом `russian-critic-protocol.md` (24 группы паттернов ИИ-шлака) — не вместо него: Нора Галь берёт глубже именно канцелярит и живость слова, общий каталог шире (кальки, декоративность, артефакты общения с ассистентом и т.д.).

## Когда применять

Дополнительно к обычному проходу `russian-critic-protocol.md`, когда текст подозревается в канцелярите/казённости — или всегда, если хочется дать более авторитетную, дословно цитируемую диагностику вместо общей.

## Пятнадцать признаков канцелярита

1. Вытеснение глагола причастием, деепричастием, существительным (особенно отглагольным) — застойность фразы.
2. Пристрастие к инфинитиву.
3. Нагромождение существительных в косвенных падежах, длинные цепи родительных.
4. Обилие отглагольных существительных.
5. Обилие иностранных слов там, где их можно заменить русскими.
6. Вытеснение активных оборотов пассивными.
7. Тяжёлый, запутанный строй фразы, несчётные придаточные.
8. Серость, однообразие, штамп.
9. Предпочтение длинного слова короткому, официального — разговорному, штампа — живому образу.
10. Словесная алгебра: обобщённые слова вместо конкретных (факт, момент, шанс, вещь, фигура).
11. Метастазы штампа: разрастание пустых слов вокруг живого ядра.
12. Официальная окраска иностранных слов в бытовых контекстах.
13. Механическое калькирование без поиска русского эквивалента.
14. Стилистический разнобой: канцелярские и живые слова в одной фразе.
15. «Нервы» и «раздражение» вместо точных эмоциональных слов.

## Словарь замен «мёртвое → живое» (выборка, дословно из книги)

| Мёртвое | Живое |

| поставить в известность | сказать |
| мы провели большую работу по сбору макулатуры | мы собрали много макулатуры |
| принимают активное участие в борьбе за повышение производительности | повышают производительность труда |
| население, проживающее | жители района |
| зверь совершил нападение | зверь напал |
| нами обнаружено | мы обнаружили |
| он находился в состоянии полного упадка сил | он совсем ослабел |
| он почувствовал страх | ему стало страшно; он испугался |
| не сам факт неудачи послужил причиной отчаяния | не сама неудача привела его в отчаяние |
| в этот роковой момент | в эту роковую минуту |
| у нас мало шансов на победу | едва ли мы победим |
| стол стоял в центре комнаты | посреди комнаты |
| он позволил себе сделать короткий антракт в работе | перерыв, передышку |
| не могу это игнорировать | не могу закрывать на это глаза |
| это произвело неожиданный эффект | поразило, подействовало |
| экономика страны базируется на четырёх китах | стоит, опирается на четырёх китах |
| им остаётся только одна альтернатива | они оказались перед выбором |
| абсолютно невозможно | никак нельзя |
| абсолютная темнота | непроглядная тьма |

Полный словарь — в исходном скилле (`Halfofthesky/nora-gal/references/slovar-zamen.md`), не дублируется здесь целиком. Критерий применения — не механическая подстановка: замена выбирается по смыслу + окраске + характеру говорящего + эпохе, одно и то же мёртвое слово в разных местах требует разных живых замен.

## Ключевые принципы (для калибровки решения, не только списка слов)

- Суть почти всегда можно выразить вдвое-втрое короче — и выйдет живее.
- Глагол — самое действенное слово; отглагольные существительные сушат текст.
- Расхожие обобщённые слова («это», «вещь», «факт», «момент») — «словесные иксы и игреки», в 99 случаях из 100 выбрасываются без ущерба.
- Иностранное слово в русском тексте получает казённую окраску, даже если в языке-источнике обыденно — но термин на своём месте не болезнь; вводить с тактом и мерой, не пуризм.
- **Не переписывать голос автора.** Правка «мне так больше нравится» — произвол; у каждой правки должно быть основание — принцип, который можно назвать.
- **Не вычищать всё подряд.** Живое нестандартное слово, инверсия, просторечие могут быть точным авторским выбором. «Редактор, признающий только асфальтовый язык, — угроза живому языку» — это тот же анти-гиперкоррекционный принцип, что уже есть в v0lka-процедуре (Шаг 3), только сформулированный автором книги, из которой вырос сам термин «канцелярит».

## Формат находки (согласован с форматом `critic-rubric.md`)

**Было:** «мы провели большую работу по сбору макулатуры»
**Стало:** «мы собрали много макулатуры»
**Почему:** отглагольное существительное + пустой глагол «провели» — ядро канцелярита; смысл несёт глагол «собрали».
