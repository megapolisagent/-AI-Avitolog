# Авитолог

Готовая карточка объявления на Avito, финансовый расчёт офферов и платформенная механика (фид, API) — вместо часа собственной работы над текстом, цифрами и выгрузкой.

Вы даёте условия объекта (цена, планировка, рассрочка/ипотека) — агент отдаёт SEO-заголовок, текст первого экрана, ТЗ на фото-карусель, скрипт первого автоответа в чат, и собирает/валидирует `feed.xml` для Автозагрузки. Работает с официальным API своего аккаунта — публикация, аналитика, мессенджер.

## Пример

> «Сделай карточку на ЖК Символ, 2-комн, 62 м², 28 млн ₽, рассрочка 0% на 12 мес, ПВ 20%»

Агент отдаёт: заголовок под поиск Avito, ТЗ дизайнеру на плашку обложки, финансовый расчёт для первого экрана, первый автоответ в чат.

## Что делает

- Упаковка карточки-локомотива: заголовок и геопривязка, текст первого экрана, ТЗ на визуал, призыв, скрипт чат-воронки.
- Финансовый калькулятор офферов (полная цена / заниженный платёж по рассрочке-ипотеке) — детерминированным кодом, не прикидкой.
- Медиаплан продвижения; ставка CPA/CPX-аукциона, включать ли платное продвижение (VAS), разбор подозрительного звонка — через субагента `traffic-manager`.
- Анализ спроса, цен и выдачи конкурентов по ЖК/локации — самостоятельно, через Apify и открытые источники: активные лоты, разброс цены за м², офферы, сила продвижения, аудит чужих карточек, рекомендация по цене и стратегии захода.
- Сборка и валидация `feed.xml`, интеграция по официальному API (Автозагрузка, Авторизация, Продвижение/BBIP/TrxPromo, Мессенджер, аналитика).

## Данные о рынке

Официальный API своего аккаунта, Apify (открытые рыночные данные), открытые сайты застройщиков, материалы, переданные вручную в `data/market_raw/` — см. `.claude/rules/open-site-access.md`.

## Автономия

Публикация нового лота, изменение цены, платное продвижение — только по явному «да» владелицы. Упаковка текста, анализ спроса и конкурентов, финансовые расчёты, сборка/валидация фида, чтение аналитики — автономно.

## Когда не подходит

Не выбирает аудиторию, сегмент или приоритетные ЖК — это готовится заранее (CMO/владелица) и передаётся как вход.

## Структура репозитория

```
CLAUDE.md              — роль, автономия, источники данных
.claude/rules/         — постоянные правила
.claude/skills/        — avito-listing-packaging (оркестратор), listing-copywriter,
                          listing-seo-geo, listing-fin-offer, cro-auditor, humanizer,
                          lead-magnets, traffic-calculator
.claude/agents/        — market-analyst, pain-point-extractor, traffic-manager
                          (советник по CPA/CPX/VAS), reviewer (независимая проверка)
knowledge/              — механика площадки, справочники API (knowledge/reference/),
                          схема фида, источники данных лота
memory/, MEMORY.md      — что агент знает о владелице и о ходе работы
data/lots/, data/market_raw/ — входные данные (свои лоты / переданные вручную материалы)
workspace/              — готовые пакеты, kpi-tracker
tests/                  — unittest на детерминированные скрипты
avito_api_client.py, avito_messenger_client.py, scripts/ — рабочий код интеграции
```
