# Авитолог

Готовая карточка объявления, план продвижения на Avito и разбор конкурентов — вместо часа собственной работы над текстом и цифрами.

Вы даёте условия объекта от застройщика (цена, планировка, программа рассрочки/ипотеки) — агент отдаёт заголовок, ТЗ на обложку, финансовый расчёт для первого экрана и первый автоответ в чат. Вам не нужно самим придумывать, как подать рассрочку 0% или посчитать ежемесячный платёж по траншу — это делает агент.

## Пример

> «Сделай карточку на ЖК Символ, 2-комн, 62 м², 28 млн ₽, рассрочка 0% на 12 мес, ПВ 20%»

Агент отдаёт: заголовок под поиск Avito, ТЗ дизайнеру на плашку обложки, текст первого экрана (только цифры, без «развитой инфраструктуры»), готовый первый автоответ в чат.

## Четыре режима работы

| Режим | Вход | Выход |
|---|---|---|
| Карточка-локомотив | условия объекта | заголовок + ТЗ на фото + финрасчёт + призыв |
| Медиаплан | ЖК/локация, число планировок | сколько карточек, какие пороги цены, когда продвигать |
| Калькулятор офферов | условия рассрочки/ипотеки | кликабельный формат цены для карточки |
| Чат-воронка | главный триггер карточки | скрипт первого автоответа |

Плюс разбор конкурентов по 6 пунктам (заголовок, первые 3 строки, тип цены, триггеры, визуальные крючки, пробелы) — но только если в `data/market_raw/` реально лежит файл с выдачей Avito.

## Что не меняется ни в одном режиме

Агент никогда сам не заходит на Avito и не собирает оттуда данные — это решённый вопрос (`DECISIONS.md`, 2026-08-31), не открытый для повторного обсуждения под новой формулировкой. Единственный способ дать ему данные о конкурентах — вручную положить файл в `data/market_raw/`.

## Механизм доверия

Каждый содержательный ответ помечает, что реально известно, а что — предположение (ЗНАЮ/ПРЕДПОЛАГАЮ) — например, форматы платного продвижения Avito сейчас не проверены напрямую, только со слов при постановке задачи. Нет данных для расчёта (график платежей, площадь) — плейсхолдер и прямое указание, чего не хватает, не выдуманное число.

## Когда не подходит

Не выбирает аудиторию, районы или приоритетные ЖК — это готовится заранее (Marketing Strategist/владелец) и передаётся как вход. Не пишет текст голосом бренда без утверждённого мессенджинга. Не публикует объявления и не ведёт переговоры с застройщиками.

## Структура репозитория

```
HOME.md              — устав: контракт результата, что агент делает и не делает
SOUL.md               — характер, Output Contract, пример разбора
skills/
  avito-listing-packaging/   — логика 4 модулей + разбор конкурентов
knowledge/
  avito-platform-mechanics.md — правила площадки, что проверено / что нет
data/market_raw/      — сюда вручную кладётся файл с выдачей Avito для разбора
workspace/             — готовые карточки/планы по ходу работы
DECISIONS.md           — история решений, включая запрет на автосбор данных
```

Обычный markdown — любой файл можно открыть и прочитать напрямую.
