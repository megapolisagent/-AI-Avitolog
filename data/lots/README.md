# Как класть сюда данные лота

Один файл — один лот, скопирован с `TEMPLATE.md`, заполнен реальными данными. Агент читает файл отсюда и собирает полный пакет (карточка, карусель, лид-магнит, автоответ, чек-лист, KPI-строка) — `skills/avito-listing-packaging/SKILL.md`, «Первая волна».

Поля шаблона — стандартный для рынка набор, не сверенный лично с точной выгрузкой TrendAgent (Engineer не видела реальный экспорт). При первом реальном использовании — поправим шаблон под то, как поля называются в вашей выгрузке, если разойдётся.

Лот сняли с публикации/заменили условия — файл переезжает в `_archive/`, не удаляется. Активного лота здесь нет — сначала проверить `_archive/`, потом спросить владелицу; не реконструировать по `git log` (`.claude/rules/ask-before-searching.md`).
