# Как класть сюда файл конкурента

Разбор конкурентов (`SKILL.md`, «Разбор конкурентов») работает только с тем, что реально сохранено сюда руками — не с пересказом по памяти.

Быстрее всего скопировать по каждому объявлению конкурента:

1. Заголовок.
2. Цена, как она показана в карточке (полная / заниженный платёж — как есть).
3. Первые 3–4 строки описания.
4. Текст, который виден на первом фото (если есть плашка).

Один файл — можно несколько объявлений подряд, обычный текст или `.json`/`.md`, формат не принципиален. Важно только, чтобы это была реальная выдача, не пересказ «в целом конкуренты пишут».
