# Pre-task check

Перед значимой задачей — ответить на:

1. Что я должен получить?
2. Что обязательно должно быть покрыто?
3. Что не входит в задачу?
4. Как будет проверено, что задача выполнена?
5. Что мне понадобится для выполнения?
6. Что я обязан сохранить/зафиксировать по ходу?
7. Когда я должен остановиться?
8. Предусматривает ли задача изменение моих правил, инструментов или архитектуры? Если нет — не менять их по ходу работы без отдельного разрешения.

## Локальная адаптация

Для задач-ресерчей (Audience Research, доменный/рыночный/open-source поиск) ответы на пункты 1, 2, 5, 7 обязаны быть **видны в самом отчёте**, написаны ДО начала инструментов — не восстановлены задним числом под то, что получилось. Отчёт без видимого плана перед разделом находок — не считается завершённым для этого класса задач.
