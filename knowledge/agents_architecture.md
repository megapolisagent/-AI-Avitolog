# Архитектура API-справочников — актуальная карта и роутинг

Живой справочник, не история изменений (история — в `git log`, см. `.claude/rules/memory-rules.md`). Подключён из `avito-listing-packaging/SKILL.md` — перед любым вызовом Avito API сверяйся с чек-листом роутинга ниже, не гадай, какой файл открывать.

Источник структуры: официальные Swagger-файлы Avito Business API, присланные владельцем начиная с 2026-08-31, распознаны по `info.title`/`info.description`/списку эндпоинтов каждого файла (не по имени файла на слово). Лежат в `knowledge/reference/<модуль>/`.

## Карта справочников

| Папка | API-модуль | Файл | Что реально даёт |
|---|---|---|---|
| `00_core/` | Авторизация | `avito-api-authorization-swagger.json` | OAuth2-токен — нужен перед любым другим вызовом |
| `00_core/` | Пользователь и баланс | `avito-api-user-info.json` | Баланс кошелька, история операций, кто авторизован |
| `01_messenger/` | Мессенджер | `avito-api-messenger-swagger.json` | Чтение/отправка сообщений, вебхуки подписки — закрыт 2026-09-10 |
| `02_conversion_retention/` | Коллтрекинг | `avito-api-calltracking.json` | Кто звонил, запись звонка |
| `02_conversion_retention/` | Рейтинги и отзывы | `avito-api-ratings-reviews.json` | Чтение отзывов, автоответ на отзыв |
| `02_conversion_retention/` | Спецпредложения в мессенджере | `avito-api-messenger-offers-beta.json` | Рассылка скидки тем, кто добавил лот в избранное |
| `02_conversion_retention/` | Продвижение (VAS/BBIP) | `avito-api-promotion-swagger.json` | Заказ платного поднятия/выделения карточки — методы реализованы в `avito_api_client.py`, живо протестированы |
| `02_conversion_retention/` | TrxPromo (продвижение за комиссию) | `avito-api-trxpromo-swagger.json` | Процентная комиссия сверх сделки вместо пакета — закрыт 2026-09-10, `[УТОЧНИТЬ]` подходит ли профилю (похоже на краткосрочную аренду) |
| `03_analytics_market/` | Объявления (статистика) | `avito-api-items-stats.json` | Просмотры/статус объявления, факт применения услуги |
| `03_analytics_market/` | Аналитика по недвижимости | `avito-api-realty-analytics.json` | Соответствие цены рынку — прямой источник для честной проверки цены |
| `04_feed_technical/` | Автозагрузка v4 | `avito-api-autoload.json` | Публикация/обновление объявлений файлом — `knowledge/avito-integration-spec.md` (Модуль 1) + `scripts/generate_feed.py` |
| `05_traffic/` | CPA-аукцион | `avito-api-cpa-auction.json` | Текущие/доступные ставки за целевое действие — зона субагента `traffic-manager` |
| `05_traffic/` | Настройка цены целевого действия (CPX) | `avito-api-cpx-pricing.json` | Автоматическая ставка за звонок/сообщение — зона `traffic-manager` |
| `05_traffic/` | Действия и жалобы CPA | `avito-api-cpa.json` | Звонки/чаты, за которые списали деньги, подача жалобы на некачественный лид — зона `traffic-manager` |

## Не загружены владельцем (честность пробела, не архив)

Автотека, Авито Promo (гарантированное размещение), Управление заказами, Тарифы (транспорт). Если понадобятся — отдельная загрузка от владельца, не реконструкция самостоятельным поиском (`.claude/rules/ask-before-searching.md`).

## Авито Реклама (баннерная/медийная реклама) — новый домен, не закрыт

Спецификация получена 2026-09-10 (`Авито Реклама`, кампании/группы/креативы/рекламодатели/договоры/статистика). Решено: отдельный узкий субагент Авитолога, не расширение общей роли и не слияние с `traffic-manager` (разные API, разная механика решений). Файл ещё не размещён физически — ждёт: (1) реальную бизнес-цель (что именно продвигать баннером), (2) роль субагента с проверяемым «не делает: …». Не открывать самостоятельно до решения владельца.

## Трафик-менеджер — субагент, не отдельный агент

С 2026-09-10 `traffic-manager` — узкий субагент Авитолога (`.claude/agents/traffic-manager.md`), не отдельный топ-агент. Справочники — `05_traffic/` выше. Прежний отдельный репозиторий «AI Traffic Manager» — в процессе вывода из эксплуатации после переноса (реальный статус — смотри дневник, не эту страницу).

## Чек-лист роутинга — какой файл/субагент открывать в каком сценарии

1. **«Хочу опубликовать карточку через фид»** → `04_feed_technical/avito-api-autoload.json` + `knowledge/avito-integration-spec.md` (Модуль 1) + `scripts/generate_feed.py` — схема XML-тегов не подтверждена официально, см. открытый вопрос там же.
2. **«Пришло сообщение от покупателя»** → `01_messenger/avito-api-messenger-swagger.json` + `avito_messenger_client.py`. Быстрый ответ (SLA ~2 минуты) — инфраструктура ещё не спроектирована, открытый вопрос (дневник 2026-09-10).
3. **«Проверить, не завышена ли цена лота»** → `03_analytics_market/avito-api-realty-analytics.json`.
4. **«Клиент оставил отзыв, нужен ответ»** → `02_conversion_retention/avito-api-ratings-reviews.json`.
5. **«Заказать поднятие объявления (VAS/BBIP)»** → `02_conversion_retention/avito-api-promotion-swagger.json`, методы в `avito_api_client.py`.
6. **«Сколько платим за звонки/сообщения, поднять ли ставку»** → субагент `traffic-manager` (справочники `05_traffic/`), не звать API напрямую самому.
7. **«Похоже, звонок был спам — вернуть деньги»** → субагент `traffic-manager`, Модуль 3.
8. **«Настроить баннерную рекламу»** → пока некуда — домен не закрыт, см. раздел выше.
