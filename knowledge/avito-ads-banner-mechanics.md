# Баннерная/медийная реклама Avito («Авито Реклама») — механика

> Собрано Engineer 2026-09-10 через WebSearch/WebFetch (официальные страницы `ads-help.avito.com` +
> перепроверка независимыми источниками), не из внутреннего API-справочника — публичного API у этого
> продукта нет, только веб-кабинет. Маркеры ЗНАЮ/ПРЕДПОЛАГАЮ — по `.claude/rules/epistemic-markers.md`.

## Форматы (ЗНАЮ — `ads-help.avito.com/formats`)

Медийный премиум (CPM), медийный стандарт (CPM), нативный баннер (CPC), баннер на главной (CPM),
баннер в профиле продавца (CPM), видео (CPM), HTML5 (CPM).

## Запуск (ЗНАЮ — `ads-help.avito.com/ads/launch`)

Кампания → минимум одна группа → минимум один креатив → кнопка «Запустить кампанию».

**Финансовый порог:** суммарный бюджет кампании больше 5000₽ с НДС, и свободный остаток на балансе
кабинета — тоже больше 5000₽. Оба условия одновременно.

## Рекламодатель и ОРД (ЗНАЮ — `ads-help.avito.com/ads/advertiser`)

Данные рекламодателя (ИНН) обязательны при запуске, уходят в **Единый реестр интернет-рекламы (ОРД)**
— это требование закона РФ о маркировке рекламы, не формальность площадки. После запуска кампании
данные рекламодателя не редактируются.

## Кто может запускать (ПРЕДПОЛАГАЮ — независимые источники, не с официальной страницы напрямую)

Кабинет доступен только юрлицам и ИП. Оплата — только безналичным платежом с расчётного счёта
российского юрлица. Самозанятые и физлица — доступны только базовые услуги Avito Pro, этот кабинет
для них закрыт. Регистрация — `avito.ru/ads`.

## Что НЕ подтверждено

- Модерация креативов/сроки — не найдено на проверенных страницах.
- Конкретные CPM/CPC-ставки в рублях — площадка их не публикует как фиксированный прайс.
- Применимость к продаже одного конкретного лота (а не бренд-кампании застройщика) — отдельного
  подтверждения нет; логически баннер ведёт на внешний сайт/лендинг или страницу бизнеса, не на
  конкретную карточку — если посадочной страницы под конкретный лот нет, канал нерелевантен, но это
  вывод из механики формата, не отдельно подтверждённый факт про эффективность.
