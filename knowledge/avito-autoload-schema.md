# Схема XML-тегов Автозагрузки — рабочая, не финально подтверждённая

Статус: получена от владельца текстом в чате 2026-09-01, не как скачанный официальный файл (в отличие от `knowledge/reference/avito-api-authorization-swagger.json` и `avito-api-promotion-swagger.json`, которые пришли реальными файлами и подтвердились живым вызовом API). Это не значит «неверно» — значит «не тот же уровень доказательства», честно помечено.

## Теги (рабочая версия)

```xml
<Ad>
    <Id>...</Id>
    <Category>Квартиры</Category>
    <OperationType>Продам</OperationType>
    <MarketType>Новостройка</MarketType>
    <HouseType>...</HouseType>
    <Floor>...</Floor>
    <Floors>...</Floors>
    <Rooms>...</Rooms>
    <Square>...</Square>
    <KitchenSpace>...</KitchenSpace>
    <Price>...</Price>
    <Address>...</Address>
    <Title>...</Title>
    <Description><![CDATA[...]]></Description>
    <NewDevelopmentId>...</NewDevelopmentId>
    <Status>Квартира</Status>
    <Images>
        <Image url="..."/>
    </Images>
</Ad>
```

Отдельно ЗНАЮ (официально, `support.avito.ru/articles/4341`): тег `<AvitoId>` реально существует и используется для привязки записи фида к уже опубликованному вручную объявлению — не нужен для нового объявления, публикуемого впервые через фид.

## Как эта схема реально проверяется — не через WebFetch

`avito.ru`/`developers.avito.ru` заблокированы для автоматического чтения (антибот) — попытка WebFetch/firecrawl сюда бессмысленна, не путать с «не проверено». Реальный механизм проверки, подтверждённый официально: после каждой выгрузки фида Avito сам создаёт отчёт с ошибками по каждому полю (`support.avito.ru/articles/4341`, раздел «Как работает автозагрузка»). Первая реальная загрузка feed.xml с этой схемой и есть проверка — не нужно повторно просить открыть сайт, нужно посмотреть отчёт после первой отправки.

## Что подтвердить при первой реальной загрузке

Если отчёт покажет ошибку по конкретному тегу — поправить именно его здесь и в `skills/avito-listing-packaging/SKILL.md`, не переписывать всю схему с нуля.
