# Спецификация: автозагрузка (feed.xml) + Messenger API

Статус: спецификация архитектуры, не рабочий код. Часть деталей ждёт подтверждения от владелицы (см. `avito-official-api-status.md`) — не додумана вместо подтверждения.

## Модуль 1 — Генератор feed.xml (Автозагрузка)

**Механизм подтверждён официально** (`support.avito.ru/articles/4341`) — Avito сам читает файл по URL на своём расписании, публикация/обновление автоматические после этого шага.

Поток:
1. Владелица утверждает текст карточки (`avito-listing-packaging`).
2. Утверждённый пакет конвертируется в один `<Ad>`-блок и добавляется/обновляется в `feed.xml`.
3. `feed.xml` должен быть доступен Avito по стабильному публичному URL — файл на локальном диске Avito не увидит.
4. Подтверждённый реальный тег — `<AvitoId>` (для связки с уже опубликованным объявлением). Полная схема тегов — `knowledge/avito-autoload-schema.md`, рабочая версия, проверяется реальной выгрузкой.

## Модуль 2 — Messenger API (чаты, автоответы, статусы)

**Подтверждено:** портал `avito.ru/developers` реален, в каталоге есть Messenger API. OAuth2 client-credentials — стандартный, общеизвестный паттерн.

**Не подтверждено, `[УТОЧНИТЬ]`:** точный token endpoint, base URL API, формат запроса на отправку сообщения/чтение чата. Не брать эти детали из непроверенных сторонних источников (см. `avito-official-api-status.md`).

Учётные данные — `.env` (реальные значения, не в git), `.env.example` (структура, безопасно коммитить):
- `AVITO_CLIENT_ID`, `AVITO_CLIENT_SECRET` — получены, сохранены.
- `AVITO_TOKEN_URL`, `AVITO_API_BASE_URL` — `[УТОЧНИТЬ]`.

Три заявленные функции — план, реализация ждёт endpoint'ы:
1. **Получение входящих сообщений** — webhook или polling, зависит от реального API.
2. **Автоответы-квалификаторы** — использует готовый скрипт чат-воронки (`avito-listing-packaging`) как текст, отправка — через API после endpoint'а.
3. **Мониторинг статусов** — возможно, не нужен отдельный вызов: `support.avito.ru/articles/4341` уже описывает отчёт после каждой выгрузки фида.

## Что нужно от владелицы, чтобы уйти от `[УТОЧНИТЬ]`

1. Содержимое `avito.ru/autoload/documentation/templates` (шаблон XML) — из личного кабинета.
2. Содержимое `avito.ru/developers/api-catalog/messenger/documentation` — из личного кабинета.
3. Решение по хостингу `feed.xml` — где физически будет лежать файл, чтобы Avito мог его читать по URL.
