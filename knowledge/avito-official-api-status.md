# Официальные каналы автоматизации Avito — что подтверждено, что нет

## ЗНАЮ (прямой fetch `support.avito.ru`, официальный первоисточник)

**Автозагрузка (Autoload)** — реальный, официальный механизм публикации СВОИХ объявлений. Источник: `support.avito.ru/articles/4341`.

- Механизм: собираете файл (XML/XLSX/CSV) со своими объявлениями → загружаете/привязываете его в профиле (`avito.ru/autoload`) → Avito читает файл по расписанию → публикует/обновляет объявления сам.
- Для недвижимости — доступно сразу после подключения платного тарифа, без доп. подписок.
- Подтверждённый реальный тег XML-формата — `<AvitoId>`.
- Точная полная схема полей XML — не подтверждена официальным шаблоном напрямую (`avito.ru` блокирует автоматическое чтение) — рабочая версия в `knowledge/avito-autoload-schema.md`.

## Messenger API — закрыто 2026-09-10

ЗНАЮ: официальная Swagger-спецификация получена от владельца целиком, сохранена — `knowledge/reference/01_messenger/avito-api-messenger-swagger.json` (методы: отправка/удаление сообщений, изображения, голосовые, подписки на вебхуки v3, чаты v2). Детали (OAuth-flow, endpoint'ы, формат ответа) — из этого файла, не из стороннего источника. Прежняя пометка «НЕ ЗНАЮ, единственный источник — подозрительный сторонний репозиторий» здесь больше не актуальна и снята.

## WebFetch на `avito.ru`/`developers.avito.ru` — не переспрашивать

Домен физически блокирует автоматический доступ (антибот/капча), независимо от числа попыток. Реальная проверка XML-схемы — отчёт Avito после первой реальной выгрузки фида, не повторный WebFetch.

## Что нужно, чтобы закрыть оставшийся честный пробел

Точная XML-схема Автозагрузки — зайти в свой профиль → «Автозагрузка» → скачать/открыть шаблон, прислать содержимое. Единственный оставшийся пробел из двух, что были на этой странице — Messenger закрыт выше.
