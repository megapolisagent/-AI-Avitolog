# Механика площадки Avito — что проверено, что нет

> Копилка знаний. Дополняется по ходу работы. Источник и дата — на каждый пункт.

---

## ЗНАЮ (проверено, источник указан)

- **У Avito нет публичного API для массового получения чужих объявлений.** Официальный Avito Pro API существует, но весь его периметр — управление СВОИМИ клиентами/кампаниями (аналитика расходов, проверка контрагентов по ИНН), не чтение чужих карточек. Источник: xmldatafeed.com, 2026-08-31 (через Researcher, `AI Intelligence/knowledge/evidence/2026-08-31-avito-competitor-data-legal-channels.md`).
- **Платная «Авито Аналитика» для Недвижимости (4000–8000 ₽/мес)** — не даёт видимость конкурентов, а наоборот, одна из функций скрывает конкурентов с карточки заказчика. Не решает задачу разбора чужих объявлений. Источник: Researcher, там же.
- **Анти-дубликат.** Avito блокирует объявления с совпадающим или очень похожим фото/описанием на один и тот же объект — работает даже между разными аккаунтами. Но: официально разрешено второе объявление на ту же квартиру с другого профиля, если контент реально уникален (другое фото, другое описание). Практический вывод для Модуля 2 — пул из нескольких офферов на одну планировку (ипотека/рассрочка/ПВ) допустим, только если у каждой карточки реально разный текст и разное фото, не один шаблон с подставленными цифрами. Источник: официальные страницы `support.avito.ru`, факт-чек Researcher 2026-08-31, `AI Intelligence/knowledge/evidence/2026-08-31-avito-antidup-stopwords-price-moderation-factcheck.md`.
- **Правила модерации карточки, подтверждённые официально:** запрет ссылок на соцсети/внешние сайты в тексте; запрет номера телефона в тексте объявления; поле «Цена» — только полная стоимость лота, первоначальный взнос/платёж по ипотеке или рассрочке — только в описании, не в поле цены (дословная цитата Avito). Этаж сверяется технически с Росреестром через номер квартиры — неверный этаж официально названная причина отклонения. «Недостоверная цена / несуществующий объект» — официально названная причина блокировки (объект уже продан/сдан, цена по телефону не совпадает с объявленной, цена аномально ниже аналогов в доме) — общий механизм, не специфика бизнес-класса. Источник: тот же факт-чек.
- **Отклонённые утверждения внешнего текста (не подтвердились).** «Гарантированный доход» как стоп-слово, автоматически банящее объявление — НЕ подтверждено: официального списка нет, найдены живые объявления недвижимости на Avito с этой фразой в тексте. Обязательность указания секции — не подтверждено и не опровергнуто, честно не проверено. Специфичность модерации именно для бизнес-класса — не подтверждено, механизм общий для всей недвижимости.

- **13 официальных Swagger-файлов API Avito, реально скачаны владельцем из личного кабинета разработчика 2026-09-01** — `knowledge/reference/avito-api-*.json`. Прочитаны напрямую (title/paths), не пересказ: Авторизация, Продвижение (BBIP), Автозагрузка (20 методов, включая `POST /autoload/v2/profile` — настройка профиля автозагрузки через API, потенциально в обход заблокированного UI), CPA-аукцион, CallTracking, Автостратегия, CPA Авито, Настройка цены целевого действия, Объявления/статистика, Рейтинги и отзывы, Аналитика по недвижимости (`marketPriceCorrespondence`, `report/create`), Спецпредложения в мессенджере (рассылка скидок — не то же самое, что чат), Информация о пользователе/баланс. **Чего среди них нет — сам Мессенджер (чтение чатов, отправка сообщений)** — единственный раздел без официального файла, остаётся на уровне «подтверждено живым вызовом API 2026-09-01, не файлом».
- **Официальный API «Продвижение» (Promotion) — реальный, подтверждён официальной Swagger 3.0 спецификацией**, полученной владельцем из своего кабинета разработчика. Сервер `https://api.avito.ru/` (совпадает с Authorization API — второе независимое подтверждение домена). Реальные методы: `POST /promotion/v1/items/services/dict` — словарь реальных типов/слагов услуг продвижения (это и есть источник настоящих названий пакетов, x2/x5/XL и т.п. — сам вызов ещё не сделан); `POST .../bbip/suggests/get` — варианты бюджета; `PUT .../bbip/orders/create` — заказ услуги; `POST .../orders/status` — статус заявки. Файл сохранён — `knowledge/reference/avito-api-promotion-swagger.json`.
- **Официальный API «Авторизация» — подтверждён той же Swagger-спецификацией.** `POST https://api.avito.ru/token`, `grant_type=client_credentials` + `client_id`/`client_secret` (form-urlencoded) → `access_token` на 24 часа. Официальные условия — `avito.ru/legal/pro_tools/public-api`. Файл сохранён — `knowledge/reference/avito-api-authorization-swagger.json`. Проверено живым вызовом 2026-09-10 — код 200, реальный токен получен.

- **Официальный API «Продвижение» (Promotion/BBIP) — полная спецификация получена от владельца 2026-09-10, реализована в `avito_api_client.py`.** Единственный из 13 API, у которого весь этот разговор не было ни файла, ни кода — закрыто. Реальные слаги пакетов, подтверждённые живым вызовом `get_promotion_services_dict()` в тот же день (не догадка, не «со слов внешнего источника», настоящий ответ API):

  | Слаг | Название |
  |---|---|
  | `bbip` | Продвижение (с прогнозом) |
  | `highlight` | Выделение |
  | `x2_1` / `x2_7` | До 2 раз больше просмотров, на 1 / 7 дней |
  | `x5_1` / `x5_7` | До 5 раз больше просмотров, на 1 / 7 дней |
  | `x10_1` / `x10_7` | До 10 раз больше просмотров, на 1 / 7 дней |
  | `x15_1` / `x15_7` | До 15 раз больше просмотров, на 1 / 7 дней |
  | `x20_1` / `x20_7` | До 20 раз больше просмотров, на 1 / 7 дней |
  | `xl` | XL-объявление |
  | `stickerpack_x1`/`x2`/`x3` | 1-3 значка на XL-объявлении |

  Цены и прогноз прироста просмотров под конкретное объявление — отдельный вызов (`get_bbip_suggests`/`get_bbip_forecast`), зависят от объявления и бюджета, не единое число для всех. Порядок реального подключения — строго `dict → get_active_services_by_items → get_bbip_suggests → get_bbip_forecast → create_bbip_order → get_bbip_order_status`, пропускать шаги нельзя. Оплата — только с Кошелька Авито. `create_bbip_order` реально тратит деньги — вызывать только после явного «да» владелицы (`CLAUDE.md` §9).

- **Официальный API «TrxPromo» (продвижение за комиссию) — полная спецификация получена от владельца 2026-09-10, реализована в `avito_api_client.py`.** Отдельный от BBIP механизм: не предоплаченный пакет просмотров, а процентная комиссия (1–15%, в сотых долях — 1500 = 15%) сверх базовой комиссии сделки, которая прибавляется автоматически. Три метода: `get_trxpromo_commissions` (`GET /trx-promo/1/commissions` — проверка доступности и вилки ставки по объявлениям), `apply_trxpromo` (`POST /trx-promo/1/apply` — запуск, реально включает платное продвижение), `cancel_trxpromo` (`POST /trx-promo/1/cancel`). Коды ошибок: 1001 — валидация параметров, 1002 — продвижение за комиссию недоступно объявлению. Файл сохранён — `knowledge/reference/02_conversion_retention/avito-api-trxpromo-swagger.json`. `apply_trxpromo` — тот же уровень риска, что `create_bbip_order`: вызывать только после явного «да» владелицы (`CLAUDE.md` §9). **[УТОЧНИТЬ]** — сама спецификация упоминает «мгновенное бронирование» как фактор базовой комиссии, что указывает на краткосрочную аренду, не на продажу/долгосрочную аренду новостроек (профиль Авитолога сейчас); подходит ли этот метод под реальные объекты владелицы — не подтверждено, вызов сделан не был.

## ПРЕДПОЛАГАЮ (косвенные источники, не подтверждено напрямую на сайте Avito)

- **Официальный Messenger API для автоответов бизнес-аккаунтам.** По вторичным источникам (блоги про автоматизацию Avito-чатов — umnico.com, otveto.ru и другие) у Avito есть официальный API для работы с чатом/автоответами, токен генерируется в профессиональном кабинете. Прямого источника на developers.avito.ru нет — домен недоступен для проверки. Открытый вопрос, не закрыт.
- **Текстовая плашка поверх фото-обложки («Рассрочка 0%» и т.п.) как разрешённый элемент карточки на Avito.** Термин реальный (подтверждён на сайтах застройщиков бизнес-класса — Эталон, Level, ФСК), но использование именно как оверлей на фото органической карточки-локомотива задокументированным кейсом не подтверждено — найденный реальный пример (ConvertMe/ГК «ТОЧНО») использовал такой текст на платном рекламном баннере Avito.Рекламы, не на фото самой карточки. Отдельная находка требует осторожности: на американском MLS-рынке текстовые оверлеи на фото объявления формально запрещены правилами площадки (нарушение → отклонение фото + штраф агента, источник — brokerless.com, отраслевой гайд). У Avito такого прямого запрета в проверенных материалах не найдено, но и подтверждения, что это разрешено, тоже нет — честно ПРЕДПОЛАГАЮ, не ЗНАЮ. Источник разбора: Researcher, `AI Intelligence/knowledge/evidence/2026-08-31-avito-locomotive-card-business-class-newbuild.md`. Открытый вопрос по проверке, не закрыт.
