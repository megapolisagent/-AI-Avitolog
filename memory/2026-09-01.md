# Дневник 2026-09-01

## Первый реальный полный пакет — ЖК ALIA, 2-комн. 46,2 м²

### Что сделали
- Реальный API Avito подтверждён живыми вызовами: `--check-token`, `--check-self-id` (user_id 444902570), `--check-chats` (0 чатов — ожидаемо, объявлений ещё нет) — все три прошли.
- Механизм Автозагрузки (feed.xml) подтверждён официально (`support.avito.ru/articles/4341`) — публикация СВОИХ объявлений, не парсинг.
- Решение `DECISIONS.md` от 2026-08-31 (полный запрет доступа к Avito) сужено, не отменено: официальный API для своего аккаунта разрешён, парсинг чужих данных — по-прежнему нет.
- Собран первый реальный полный пакет на реальном лоте (ЖК ALIA, Asterus): карточка-локомотив, финансовый калькулятор, скрипт чат-воронки, XML-блок — все 4 части, владелец утвердила по содержанию.
- `feed.xml` собран локально в корне репозитория, обёрнут в `<Ads formatVersion="3" target="Avito">`.

### Что осталось
- **Реальные фото** — в `feed.xml` заглушка вместо URL, ждём от застройщика.
- **Хостинг feed.xml** — файл лежит локально, для реальной автозагрузки нужен публичный URL (ngrok/cloudflared/GitHub Pages/S3 — решение владельца, не реализовано технически).
- **Send_auto_reply не проверен на реальном сообщении** — код готов и три более дешёвых вызова прошли, но чатов пока 0, реальной отправки живому покупателю ещё не было.
- **Схема XML feed** — получена текстом от владельца, не файлом (в отличие от Authorization/Promotion) — настоящая проверка будет после первой реальной загрузки, по отчёту от Avito.

### Решения
- Прямой доступ к Avito API/Автозагрузке для своего аккаунта — Locked, 2026-09-01 (`DECISIONS.md`).
- WebFetch на `avito.ru`/`developers.avito.ru` не работает физически (антибот) — не переспрашивать, реальная проверка через живой вызов/загрузку, не через чтение документации (`instructions/avito-official-api-status.md`).
