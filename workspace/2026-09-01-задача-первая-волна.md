# 2026-09-01 — Задача: остановить усложнение, собрать рабочий контур на первую волну

## Слова владельца (дословно)

«Останавливаем дальнейшее усложнение «Авитолога»: новые memory-файлы, ревью и общие доработки не являются приоритетом, пока нет первой опубликованной волны.

Зафиксируй честно текущую роль агента: он не парсер Авито и не исполнитель публикации. Его реальная функция — упаковка и конверсия карточек по подтверждённым данным лота.

Нужен не новый теоретический агент, а рабочий операционный контур на первую волну размещения. Собери единый шаблон входных данных по лоту из TrendAgent/кабинета застройщика и единый выходной пакет: карточка объявления, ТЗ на карусель, лид-магнит, первый автоответ, чек-лист модерации и строка для таблицы KPI.

Критерий готовности — не «чек-лист агента закрыт», а «на основе одного реального лота создан полный пакет, который я могу опубликовать сегодня без дополнительной переработки».

Отдельно предложи, как мы будем получать входные данные легально и регулярно: выгрузки TrendAgent, документы и прайсы застройщиков, собственные отчёты Авито Pro, данные из CRM. Не предлагай новые архитектурные доработки без прямой связи с первой волной из 10 карточек.»

## Критерий достаточности (зафиксирован до работы)

1. `HOME.md` честно отражает роль (не парсер, не публикатор — упаковка/конверсия по подтверждённым данным) и текущий приоритет (первая волна, не полнота процесса).
2. Единый входной шаблон лота (поля из TrendAgent/кабинета застройщика/CRM) — один файл-шаблон, не разбросан по нескольким модулям.
3. Единый выходной пакет — один прогон, шесть частей: карточка объявления, ТЗ на карусель, лид-магнит, первый автоответ, чек-лист модерации, строка для таблицы KPI.
4. Предложение по источникам входных данных (TrendAgent/документы застройщика/Авито Pro отчёты/CRM) — легальность и регулярность каждого явно.
5. Не входит: новые Skills/memory-файлы/ревью-циклы, не привязанные напрямую к пункту 2-3 выше.
6. Финальная проверка критерия — реальный лот от владельца, не гипотетический пример (владелец должен дать данные отдельно, агент/Engineer их не выдумывает).
